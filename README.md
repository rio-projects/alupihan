# Saver Rover

Android rover controls and offline YOLO11 Large person detection, with ESP32 motor
controller and ESP32-CAM MJPEG firmware.

- [YOLO setup, model export, controls, and validation](docs/YOLO_INTEGRATION.md)
- [System documentation](docs/README.md)

Build the Android app from `SaverRover` with `./gradlew :app:assembleDebug`.
Run regression tests with `./gradlew :app:testDebugUnitTest`.
